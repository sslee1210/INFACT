이번 단계에서 실제로 정리한 항목

1. 가로 오버플로 위험 제거
- 모바일 메뉴 width의 100vw 사용 제거
  width: min(440px, 100vw) -> width: min(440px, 100%)
  width: 100vw -> width: 100%
- 모바일 메인 Contact full-bleed의
  calc(50% - 50vw) 방식 제거
- site-edge-gutter 기준으로 정확히 확장하도록 변경
- html/body overflow-x fallback 추가
  hidden 기본 + 지원 브라우저에서 clip 사용

2. 모바일 메뉴 viewport 높이 fallback
- 100dvh만 사용하던 구조에 100vh fallback 추가
- 구형 브라우저에서도 메뉴 높이가 무너지지 않도록 보강

3. 불필요한 breakpoint 제거
- About 다이어그램의 중복 max-width: 560px 보정 블록 삭제
- 이미 max-width: 767px 규칙과 동일했던 중복 CSS 제거

4. 최종 QA Guardrail 신규 추가
파일:
client/src/styles/common/responsive-qa-stage7.css

기능:
- grid/flex 자식 min-width: 0 보강
- 긴 영문 기술문서명 / 이메일 / 프로젝트명 overflow-wrap 보강
- 이미지 / SVG / iframe 컨테이너 이탈 방지
- 767/768, 1199/1200 전환점 안전장치
- 모바일/태블릿에서 데스크톱 mega menu 강제 비표시
- 1200px 이상에서 mobile drawer 잔존 방지
- touch 기기에서 hover 이동 효과 제거
- reduced-motion 보강

5. 자동 반응형 무결성 검사 스크립트 추가
파일:
scripts/check-responsive-integrity.mjs

검사 항목:
- CSS 중괄호 구조
- 중복 import
- Stage 1~7 import 순서
- Stage 7 최종 import 여부
- 100vw 사용 금지
- calc(50% - 50vw) 금지
- overflow-x: auto/scroll 금지

6. package.json QA 명령 추가
- corepack pnpm qa:responsive
  반응형 CSS 정적 무결성 검사

- corepack pnpm qa
  TypeScript check
  + 반응형 무결성 검사
  + production build
