6단계 실제 리팩터링 — 공통 UI 시스템 / Contact / Footer

기준
- 사용자가 커밋한 최신 main의 Stage 1~5 반응형 구조를 기준으로 작업
- 기존 페이지 디자인을 새로 갈아엎지 않고 공통 요소의 중복과 불일치를 정리

1. 디자인 시스템 토큰 신규 구축
파일:
client/src/styles/common/design-system.css

추가한 공통 기준:
- 8pt spacing: 8 / 16 / 24 / 32 / 48 / 64 / 80 / 96 / 120
- Typography token
- Button/control height
- Touch minimum
- Border / surface
- 200ms motion
- Desktop / Tablet / Mobile section rhythm

2. 공통 버튼 시스템
클래스:
.ui-button
.ui-button--primary
.ui-button--secondary
.ui-button--outline
.ui-button--text
.ui-button--compact

현재 Header '문의하기' 버튼부터 공통 시스템에 연결했습니다.

3. Service Contact CTA 공통화
- 개념설계 / GMP / CSV가 모두 사용하는 ServiceContact에 ui-line-link 연결
- 기존 사용자가 확정한 SVG 수평선+사선 형태는 유지
- hover / transition만 공통 200ms 시스템으로 통일

4. Footer 컴포넌트 실제 리팩터링
파일:
client/src/components/site/SiteFooter.tsx
client/src/styles/common/footer.css

변경:
- hash anchor 대신 wouter Link 사용
- Navigation / Contact 의미 구조 정리
- 전화번호 클릭 가능
- Footer markup과 CSS 계층 단순화
- Desktop 2열 / Tablet 2열 / Mobile 1열
- 모바일 링크 터치영역 확대
- 420px 이하 Navigation 1열

5. Stage 2 중복 Footer responsive 규칙 제거
파일:
client/src/styles/pages/home-responsive-stage2.css

- Footer를 덮어쓰던 기존 !important 블록 삭제
- Footer 반응형 소스를 footer.css 하나로 통합

6. Contact 페이지 보완
파일:
client/src/pages/Contact.tsx
client/src/styles/common/ui-system-stage6.css

- 회사 대표 전화 클릭 가능
- 대표 이메일 클릭 가능
- 태블릿 담당자 목록을 '분야명 / 연락정보' 행 구조로 재배치
- 모바일 담당자 정보 터치영역 확대
- 지도 확대/축소 버튼 터치영역 44~48px
- 모바일 지도 주소 팝업 위치/폭 보정

7. 공통 UI 최종 레이어
파일:
client/src/styles/common/ui-system-stage6.css

- Header 버튼
- Service CTA
- Contact
- Touch target
- Reduced motion
을 한곳에서 관리

8. index.css
- variables 다음에 design-system.css import
- Stage 5 다음에 ui-system-stage6.css import
