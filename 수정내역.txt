반응형 대수정 5단계 — 수행실적 전체

범위
- 개념설계 수행실적
- GMP 수행실적
- CSV 수행실적
- 연도 선택 메뉴
- 고객사/프로젝트 카드
- 미등록 상태

공통 원칙
- 데스크톱(1200px 이상) 기존 우측 연도 메뉴 유지
- 태블릿/모바일만 새 구조 적용
- 모바일 우측 하단 floating 연도 메뉴 제거
- 가로 스크롤 없음
- 카드 고정 높이 최소화
- 고객사 로고와 수행 프로젝트의 정보 위계 정리

[개념설계 / GMP 수행실적]
태블릿
- 연도 메뉴를 콘텐츠 상단 5열 선택 메뉴로 전환
- 프로젝트 카드 3열
- 카드 로고 높이와 본문 패딩 축소

모바일
- 연도 메뉴 상단 3열
- 프로젝트 카드 1열
- 391px 이상: 왼쪽 로고 + 오른쪽 수행 프로젝트
- 390px 이하: 로고 위 / 프로젝트 아래

[CSV 수행실적 — 연도별 분리형]
태블릿
- 상단 4개 연도 메뉴
- 이전/다음 버튼 유지
- 카드 3열

모바일
- 상단 2개 연도 메뉴
- 이전/다음 버튼 하단 유지
- 카드 1열
- 로고와 프로젝트를 가로 정보행으로 구성

[CSV 수행실적 — 연속 아카이브형]
태블릿
- 우측 sticky 메뉴를 상단 5열 메뉴로 전환
- 카드 3열

모바일
- 기존 우측 하단 floating 연도 메뉴 완전 제거
- 상단 3열 연도 메뉴
- 연도별 섹션은 세로 문서 구조
- 카드 1열
- 390px 이하에서 완전 세로 카드

추가 파일
- client/src/styles/pages/references-responsive-stage5.css

수정 파일
- client/src/index.css
