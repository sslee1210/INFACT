긴급 수정 — Contact 버튼 중앙정렬 / CSV V-Model 전체 표시

1. Contact 버튼
파일:
client/src/styles/pages/home-responsive-stage2.css

원인:
- 모바일 최종 override에서 justify-content:flex-start
- padding-bottom:14px
- 이 두 규칙 때문에 버튼 박스 중심과 텍스트 중심이 달라짐

수정:
- display:flex
- align-items:center
- justify-content:center
- padding:0 20px
- label 자체도 flex 중앙정렬
- 가로/세로 모두 실제 중앙 정렬

2. CSV V-Model
파일:
client/src/styles/pages/service-csv-page.css

원인:
원본 컴포넌트 CSS가
- width:130%
- max-width:none
- margin:0 -15%
를 사용함

수정:
같은 service-csv-page.css 파일의 가장 마지막에서
1199px 이하 규칙을 직접 추가하여:
- width:100%
- max-width:100%
- margin:0 auto
- object-fit:contain
- transform:none
- clip-path:none

즉, 외부 반응형 override의 로딩 순서에 의존하지 않고
컴포넌트 원본 CSS 내부에서 모바일/태블릿 확대를 직접 취소함.

적용 후:
corepack pnpm dev

브라우저:
Ctrl + Shift + R

확인 폭:
390 / 430 / 768 / 1024
