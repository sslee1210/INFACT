기준
- GitHub latest committed responsive baseline: f6580e80220ac5c8ebd6b4575659a3f19daa3663
- 이전 Contact 중앙정렬 수정도 함께 포함

1. CSV V-Model
기존 문제:
.csv-vmodel img 자체에 width:130%, margin:0 -15%가 걸려 있어
모바일에서도 이미지가 컨테이너 밖으로 나갈 가능성이 있었음.

이번 수정:
- 기본(모바일/태블릿): figure 100%, image 100%, max-width 100%
- 이미지 전체 도식이 컨테이너 안에 완전히 표시
- 데스크톱 1200px 이상에서만 figure 자체를 130% 확대
- 즉 모바일에서 절대 130% 확대가 적용되지 않음

2. 모바일 토글 메뉴
기존:
- panel top이 header 높이 아래에서 시작
- 모바일에서 full width라 아래로 펼쳐지는 메뉴처럼 느껴질 수 있음

변경:
- viewport 오른쪽 끝에서 슬라이드 인
- top:0 / full viewport height
- phone: 최대 380px 또는 화면의 88%
- tablet: 최대 430px
- header는 drawer 위에 유지
- drawer 내부 콘텐츠만 header 높이 아래부터 시작
- scrim은 전체 viewport 덮음

3. 메인 홈페이지 오각형
- 모바일 width를 기존 대비 약 15% 확대
- left:50% + translateX(-50%)로 정확한 중앙 유지
- max-width:100vw로 화면 밖 과도한 침범 방지
